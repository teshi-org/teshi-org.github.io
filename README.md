# teshi.org

Minimal single-page website for [teshi](https://github.com/teshi-org/teshi), built with [Hugo](https://gohugo.io/).

## Requirements

- Hugo (extended) >= 0.144

## Local development

```bash
hugo server -D
```

Then open <http://localhost:1313>.

## Production build

```bash
hugo
```

The static site will be generated into `./public`.
